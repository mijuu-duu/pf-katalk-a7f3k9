====================================================
 단서 메신저 — 설치 및 사용 안내
====================================================

[폴더 구성]
  index.html            앱 본체 (대화 내용이 이 파일 안에 들어있음)
  manifest.webmanifest  앱 설치 기본값
  sw.js                 오프라인 캐시 + 최신 파일 우선 + 앱 이름 처리
  icons/                앱 아이콘 (192, 512)
  README_설치안내.txt   이 파일

----------------------------------------------------
1. 미개통 안드로이드에 앱으로 설치하기
----------------------------------------------------
준비물: 미개통 안드로이드 1대

 (1) 폰에 HTTP 서버 앱을 설치합니다.
     - Play 스토어에서 "Simple HTTP Server", "KSWEB", "Web Server" 등으로 검색
     - 플레이스토어는 SIM 없이도 Wi-Fi + 구글 계정만 있으면 사용 가능합니다.
     - 구글 계정을 쓰지 않으려면 PC에서 APK를 받아 USB로 옮겨 설치해도 됩니다.

 (2) zip 파일을 폰 내부저장소에 풀어 넣습니다.
     예) /storage/emulated/0/Download/단서메신저_app/

 (3) 서버 앱에서
     - 루트 폴더(Document root) = 위에서 압축을 푼 폴더
     - 포트(Port) = 8080
     로 설정한 뒤 START 를 누릅니다.

 (4) 크롬 주소창에 아래 주소를 입력합니다.
        http://localhost:8080/
     ※ 반드시 localhost 로 접속하세요. localhost 로 열어야만
        크롬이 "앱 설치"를 허용합니다. (IP 주소로 열면 설치 불가)

 (5) ★ 설치 전에 앱 이름부터 정합니다. (아래 2번 참고)

 (6) 크롬 메뉴(⋮) → "앱 설치" 또는 "홈 화면에 추가" 를 누릅니다.
     홈 화면에 아이콘이 생기고, 이후에는 아이콘만 눌러 실행하면 됩니다.
     첫 실행 이후에는 서버를 꺼도 앱이 열립니다.
     (새 파일로 업데이트할 때는 서버를 다시 켜야 합니다)

----------------------------------------------------
2. 앱 이름(홈 화면 아이콘 이름) 정하기
----------------------------------------------------
 (1) 채팅 목록 화면에서 상단 제목을 5초간 길게 눌러 관리자 모드로 들어갑니다.
 (2) "앱 / 데이터" 칸에서
       · 앱 이름 …………… 공통으로 쓸 이름
       · 이 목록만 다른 이름 … 목록별로 다른 이름을 쓰고 싶을 때만 입력
     을 넣고 "이름 저장" 을 누릅니다.
     바로 아래 "지금 설치되는 이름" 에 실제 적용될 이름이 표시됩니다.
 (3) "설치 이름 방식" 이 "정상 (이름 즉시 반영)" 인지 확인합니다.
     "준비 중" 이면 앱을 완전히 껐다가 다시 연 뒤 설치하세요.
     (처음 접속한 직후에는 이름 처리 기능이 아직 준비되지 않습니다)
 (4) 홈 화면에 이미 아이콘이 있으면 길게 눌러 삭제한 뒤 다시 설치합니다.
     ※ 아이콘 이름은 설치하는 순간의 이름으로 굳습니다.
        이름만 바꾸고 재설치하지 않으면 예전 이름 그대로 남습니다.

 · 앱 실행 순간 잠깐 보이는 로고 화면(스플래시)
   배경색은 아이콘 바탕과 같은 노란색(#fee500)으로 맞춰져 있습니다.
   색을 바꾸려면 manifest.webmanifest 와 sw.js 의 background_color 값을
   같은 색으로 함께 고치세요. 이 값도 설치 시점에 굳으므로
   바꾼 뒤에는 아이콘을 지우고 다시 설치해야 합니다.

 · 목록별로 다른 앱을 만들고 싶다면
   주소에 목록을 지정한 상태(예: ?list=사건_A)에서 그 목록의 이름을 정하고
   설치하면, 그 아이콘은 항상 그 목록을 열게 됩니다.

----------------------------------------------------
3. 여러 개의 대화 목록 쓰기
----------------------------------------------------
목록마다 완전히 다른 대화를 담을 수 있습니다.
주소 뒤에 ?list=목록이름 을 붙이면 그 목록이 바로 열립니다.

    http://localhost:8080/index.html?list=기본
    http://localhost:8080/index.html?list=사건_A
    http://localhost:8080/index.html?list=3월_살인사건

  - 목록 이름에는 한글과 밑줄(_)을 쓸 수 있습니다.
  - 없는 이름을 넣으면 기본 목록이 열리고 안내가 뜹니다.
  - 목록 추가/이름 변경/복제는 관리자 모드에서 합니다.

4. 내용 수정과 저장 규칙 (중요)
----------------------------------------------------
  · 폰에서 수정한 내용은 자동 저장되며, 앱을 껐다 켜도 그대로 유지됩니다.
  · 새로 만든 index.html 로 교체하면(=재설치) 파일 버전이 달라지므로
    폰에 저장된 이전 내용은 자동으로 지워지고 새 파일 내용이 들어갑니다.
  · 재설치가 없으면 폰에서 수정한 내용이 항상 우선입니다.
  · 관리자 모드 → "파일 원본으로 되돌리기" 로 언제든 파일 내용으로 되돌릴 수 있습니다.
  · 관리자 모드 → "내보내기" 로 백업 파일(JSON)을 만들 수 있고,
    새 파일 설치로 내용이 바뀐 뒤에도 "불러오기" 로 되살릴 수 있습니다.

  ※ 업데이트하려면 서버 앱을 켜 둔 상태에서 앱을 한 번 실행해야 합니다.
     (새 파일을 받아와야 하기 때문입니다)

  [새 파일을 알아보는 방법]
   · 파일 안의 내용이 조금이라도 다르면 새 파일로 인식합니다.
     DATA_VERSION 값을 손대지 않고 대화만 고쳐도 갱신됩니다.
   · 앱을 실행하면 1~2초 뒤 서버의 index.html 을 자동으로 확인합니다.
     새 파일이면 "새 파일을 발견했습니다" 안내가 뜨고 알아서 새 내용으로 다시 엽니다.
   · 바로 확인하고 싶으면 관리자 모드 → "새 파일 확인 (업데이트)" 를 누르세요.

  [업데이트가 안 될 때 — 예전 캐시 털어내기]
   앱을 처음 만들 때의 파일이 캐시에 남아 계속 예전 내용만 보이는 경우가 있습니다.
   아래 중 하나만 하면 됩니다.

    (가) 주소 끝에 ?reset=1 을 붙여 크롬에서 한 번 열기
         예) http://localhost:8080/index.html?reset=1
         → 저장된 내용과 캐시를 전부 지우고 파일 내용으로 다시 시작합니다.

    (나) 크롬에서 주소창 왼쪽 아이콘(자물쇠 또는 ⓘ) → 사이트 설정
         → "데이터 삭제 및 재설정"

   ※ 홈 화면 아이콘을 지워도(앱 삭제) 저장된 대화는 지워지지 않습니다.
      크롬이 사이트 데이터를 따로 보관하기 때문입니다. 위 방법을 쓰세요.

5. 다른 폰에도 같은 내용으로 배포하기  ★ 가장 중요
----------------------------------------------------
 ※ 꼭 알아두실 점
   관리자 모드에서 고친 내용은 "그 기기(브라우저)" 안에만 저장됩니다.
   index.html 파일 자체는 바뀌지 않습니다.
   그래서 PC에서 고친 뒤 그 파일을 그냥 압축해 폰으로 보내면
   폰에서는 "고치기 전 내용"이 나옵니다.
   → 반드시 아래 (2)번으로 파일을 새로 만들어서 옮기세요.

  (1) PC(또는 폰)에서 관리자 모드로 대화를 전부 만듭니다.
  (2) 관리자 모드 → "새 index.html 만들기" 를 누릅니다.
      → 다운로드 폴더에 index.html 이 저장됩니다. (지금 내용이 담긴 파일)
      → PC에서 index.html 을 그냥 더블클릭해 열었을 때도 이 버튼이 동작합니다.
  (3) 그 파일로 폴더의 index.html 을 덮어쓰고, 폴더를 zip 으로 묶어 폰에 넣습니다.
  (4) 폰에서 서버 앱을 켜고 앱을 한 번 실행하면 새 내용으로 갱신됩니다.

 · 아직 파일로 만들지 않은 수정이 있으면 관리자 모드 맨 위에
   노란 경고 칸("이 기기에만 저장된 수정이 있습니다")이 나타납니다.
   그 칸의 버튼을 눌러 파일을 만들면 됩니다.

 · 관리자 모드의 "지금 보이는 내용 / 파일 버전·지문 / 폰에 저장된 버전·지문"
   표시를 보면, 폰이 새 파일을 실제로 받았는지 바로 알 수 있습니다.
   "새 파일 확인" 을 눌렀을 때 서버 파일의 대화방·메시지 개수도 함께 보여줍니다.

 · PC에서 메모장으로 직접 고치고 싶으면 index.html 을 열어
   파일 위쪽의 __CS_DATA_START__ ~ __CS_DATA_END__ 사이만 고치면 됩니다.
   DATA_VERSION 은 그대로 둬도 내용이 다르면 자동으로 갱신됩니다.

6. 관리자 모드 들어가기
----------------------------------------------------
  채팅 목록 화면에서 상단 제목("채팅")을 5초간 길게 누릅니다.
  손님(플레이어)에게 넘기기 전에는 "손님 모드" 버튼을 눌러 두세요.
  손님 모드에서는 설정(톱니바퀴) 버튼이 사라집니다.

----------------------------------------------------
7. 다른 접속 방법 (참고)
----------------------------------------------------
 A. 다른 폰에서 서버를 돌리고 IP로 접속 (http://192.168.x.x:8080)
    → 화면은 보이지만 "앱 설치"는 되지 않습니다.
      설치까지 하려면 접속하는 폰의 크롬에서
      chrome://flags/#unsafely-treat-insecure-origin-as-secure 에
      해당 주소를 등록해야 합니다. (폰마다 1회 설정)

 B. 인터넷이 한 번이라도 연결된다면
    GitHub Pages 같은 무료 HTTPS 호스팅에 이 폴더를 올린 뒤
    크롬으로 열어 설치하는 방법이 가장 간단합니다.
    설치 후에는 인터넷 없이도 동작합니다.

8. 자주 겪는 문제
----------------------------------------------------
 · 앱 이름이 "채팅" 으로 고정됨
     → 이름을 저장했더라도 홈 화면 아이콘을 지우고 다시 설치해야 바뀝니다.
       관리자 모드의 "설치 이름 방식" 이 "정상" 인지도 확인하세요.
 · "앱 설치" 메뉴가 안 보임
     → 주소가 localhost 인지 확인하세요. file:// 이나 IP 주소로는 설치가 안 됩니다.
 · PC에서 고쳤는데 폰에서는 예전 내용만 나옴  ← 가장 흔한 원인
     → 관리자 모드에서 고친 내용은 파일에 저장되지 않습니다.
       "새 index.html 만들기" 로 파일을 만든 뒤, 그 파일을 압축해 옮기세요. (5번 참고)
 · 폰이 계속 예전 화면만 열어서 아무것도 안 통할 때
     → 서버 앱의 포트를 8080 에서 8081 로 바꿔 실행하고
       http://localhost:8081/ 로 열면 완전히 새로 시작합니다.
       (주소가 달라지면 예전 캐시·저장분이 적용되지 않습니다)
       그 뒤 예전 아이콘은 지우고 새로 설치하세요.
 · 내용을 바꿨는데 그대로임
     → 서버를 켠 상태에서 앱을 한 번 열어 새 파일을 받아야 합니다.
       그래도 안 되면 크롬 설정에서 해당 사이트 데이터를 지우고 다시 여세요.
 · 사진을 많이 넣으니 저장이 안 됨
     → 브라우저 저장 공간(약 5MB) 초과입니다. 사진 수를 줄이세요.
 · 하단 탭바가 기기 버튼에 가림
     → 관리자 모드 → "하단 여백" 숫자를 24~48 정도로 올리세요.
